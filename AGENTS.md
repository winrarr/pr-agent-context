# Project instructions

PR Agent Context is a Manifest V3 Chrome extension that turns authenticated GitHub pull request pages into user-selected Markdown. Private pull request data may be read only from same-origin GitHub routes and written only to the user-triggered clipboard; it must not be persisted or transmitted elsewhere.

## Components and contracts

- `src/github/` owns GitHub URL recognition, authenticated collection, markup parsing, and full-path resolution.
- `src/domain.ts` is the normalized contract between collection and export.
- `src/export/` renders normalized data and must not depend on GitHub markup or browser APIs.
- `src/content/` owns browser integration and the injected Shadow DOM interface; keep GitHub selectors out of it.
- `tests/fixtures/` is the compatibility contract for supported GitHub markup. Keep fixtures minimal, synthetic, and free of credentials or private content.

Prefer pure parsers and explicit failure over misleading partial context. Reproduce GitHub markup bugs with a focused fixture before repairing the parser.

## Sources of truth and boundaries

- `public/manifest.json` is the extension manifest source. `dist/` is generated by `npm run build`; never edit it.
- `package.json` defines canonical commands. `package-lock.json` is committed, and local/CI setup uses `npm ci`.
- `package.json` and `public/manifest.json` versions must agree; `npm run verify` enforces this.
- `artifacts/` contains disposable release ZIPs generated by `npm run package`.
- Permission, host-match, network, persistence, clipboard, and release-workflow changes have a wide trust or distribution impact. Keep permissions minimal, preserve the local-only data boundary, and update the relevant durable documentation.

## Canonical commands

- `npm ci` installs the pinned dependency graph on Node.js 22.
- `npm run dev` continuously rebuilds `dist/` for manual Chrome testing.
- `npm run format` formats the repository.
- `npm test` runs the parser, collection, UI, and Markdown tests.
- `npm run verify` runs every required check and creates the production bundle; CI runs the same command.
- `npm run package` verifies and creates the versioned Chrome Web Store ZIP.
